# 📚 StudyBuddy – Your Smart Study Organizer

StudyBuddy is a productivity-focused web application designed to help students organize subjects, manage tasks, track deadlines, and improve study efficiency — all in one place.

---

## 🚀 Features

### **Core Features**

🔐 **User Authentication**  
Secure registration and login using JWT for protected routes.

📖 **Subject Management**  
Create, organize, and color-code subjects for easy identification.

✅ **Task Management**  
Add tasks with deadlines, priorities, tags, and status tracking.

📁 **Resource Library**  
Attach YouTube videos, PDFs, links, or notes to subjects or tasks.

📅 **Calendar View**  
Visualize upcoming deadlines with a monthly and weekly interactive calendar.

📊 **Dashboard Analytics**  
Track task completion, study progress, and performance statistics.

🎯 **Priority System**  
Sort tasks by High, Medium, or Low priority to stay focused.

🏷️ **Tags & Filters**  
Categorize tasks and filter them based on subject, priority, or status.

🌓 **Dark Mode**  
Eye-friendly UI for long study sessions.

## 🛠️ Tech Stack

### **Frontend**
- React + Vite  
- TypeScript  
- TailwindCSS  
- Zustand / Context API (state management)

### **Backend**
- Node.js  
- Express.js  
- MongoDB + Mongoose  
- JWT Authentication
